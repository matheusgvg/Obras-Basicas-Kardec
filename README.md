# 📚✨ Desafio das Obras Básicas

> **Uma aventura de conhecimento pelas cinco Obras Básicas de Allan Kardec.**

Um jogo educativo para a **Pré-Mocidade** relacionar situações do cotidiano e dúvidas existenciais às obras do Pentateuco Kardequiano. Aprenda, reflita e descubra uma conexão nova a cada pergunta!

## 🌟 Sobre o jogo

Em cada rodada, leia um dilema e escolha qual obra pode ajudar a explorar aquele tema. Depois da resposta, confira o feedback e uma breve explicação — inclusive quando a resposta não for a esperada.

- 🎮 **8 dilemas** sobre temas do dia a dia e questões existenciais.
- 📖 **As cinco Obras Básicas** como opções em cada rodada.
- 💡 **Explicações educativas** para contextualizar as respostas.
- ✨ **Pontuação, progresso e resultado personalizado**.
- 🔁 **Jogue novamente** para rever as perguntas e tentar uma pontuação maior.
- 📱 **Interface responsiva**, pensada para celulares e tablets.
- 🔊 **Feedback sonoro** opcional durante as respostas.
- 🌌 **Imagens de livros e do universo**, carregadas do Unsplash.

## 📖 As cinco obras

1. *O Livro dos Espíritos*
2. *O Livro dos Médiuns*
3. *O Evangelho segundo o Espiritismo*
4. *O Céu e o Inferno*
5. *A Gênese*

## 🚀 Comece a jogar

O jogo está em um único arquivo HTML, sem bibliotecas, instalação ou servidor.

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador moderno.
3. Clique em **Iniciar Jogo** e divirta-se!

> As imagens decorativas são carregadas do Unsplash e precisam de conexão com a internet. O jogo continua funcionando se elas não estiverem disponíveis.

## ☁️ Publicar na Vercel

Como o projeto é uma página estática, não precisa de etapa de build.

### Importar pelo GitHub

1. Envie este projeto para um repositório na conta [@matheusgvg](https://github.com/matheusgvg).
2. Acesse [vercel.com/new](https://vercel.com/new) e entre com sua conta.
3. Importe o repositório do GitHub.
4. Nas configurações do projeto, deixe o **Framework Preset** como `Other`.
5. Deixe **Build Command** e **Output Directory** vazios; não é necessário instalar dependências.
6. Clique em **Deploy**. A Vercel publicará o `index.html` e fornecerá o endereço do jogo.

### Atualizações

Depois de conectar o repositório, cada novo push para a branch principal gera uma publicação de produção. Pull requests também podem receber URLs de preview automaticamente.
